# Tech-team-recruit

## Introduction

The goal of this repository is to evaluate the candidates skill through the code review process.

## How to launch the server
In the root directory launch the command `./mvnw spring-boot:run`
The server should be up and runnin on the url http://localhost:9966/petclinic

## How to launch the client
The first time in the client directory launch `npm install`
In the client directory launch the command `npm start`
The client should be up and runnin on the url https://localhost:3000/
